# 视频风格指南（可跨项目复用）

> 来源：UP「大Arleta」的 pixiv 排序插件视频（98 秒）+ HiPod 发布视频（57 秒）的实际制作过程。
> 用途：换一个项目时，把这份文档丢给任何 AI / 剪辑，都能产出同风格的片子。
> 一句话：**短、密、口语、有自嘲、有实物演示、不吹牛、结尾只指路。**

---

## 0. 风格 DNA（30 秒读完）

- **时长** 1–2.5 分钟，宁可短，不要空。
- **旁白** 全程覆盖，任意 2 秒内都有人声；语速约 **3.7 字/秒**（含停顿）。
- **结构** 钩子 7s → 是什么 6s → 演示 60% → 缺点 10s → 指路 5s。
- **语气** 自称「主播」；短句 10–16 字；承认跟风、承认 AI、承认没做完。
- **画面** 深色画布 + 手机实机录屏 + 右侧 Q 版角色 + 左侧信息区 + 底部字幕。
- **声音** 单一 TTS 女声（晓伊）+ 低音量 BGM + 少量 UI 音效。
- **禁忌** 「重磅 / 最强 / 吊打 / 一键三连」；长段无旁白；纯功能罗列。

---

## 1. 硬指标

| 项 | 值 |
| --- | --- |
| 画布 | 1920×1080，30fps，H.264，CRF 18 |
| 时长 | 60–150 秒（工具类 90s，产品类 120s） |
| 旁白字数 | 时长 × 3.7（例：57s ≈ 210 字） |
| 旁白密度 | ≥ 95%，任意 2s 内有人声，最长停顿 0.8s |
| 镜头数 | 6–10 个，单镜 4–15s，每 8–12s 换画面 |
| 字幕 | 42–44px，白字 + 3px 黑边，底部 140px |
| BGM | -24dB，无人声，CC0/CC-BY |
| 封面 | 16:9（1920×1080）+ 4:3（1600×1200）两版 |

---

## 2. 叙事结构（时间轴模板）

以 120 秒为例，按比例缩放：

| 段落 | 占比 | 内容 | 写法 |
| --- | --- | --- | --- |
| 钩子 | 0–6% | 一句反差 + 一个动作 | 「我把 X 塞进了 Y」 |
| 是什么 | 6–14% | 三个「没有」+ 一句定位 | 不念参数，念体验 |
| 演示 A | 14–38% | 核心交互 1–2 个 | 一个动作一句旁白 |
| 演示 B | 38–62% | 第二个卖点（本例是 hifi） | 只讲能兑现的 |
| 差异点 | 62–72% | 外观 / 手感 / 细节 | 正经描述，不用比喻堆砌 |
| 缺点 | 72–84% | 没做的功能 + 一句自嘲 | 主动说，别等人问 |
| 指路 | 84–94% | 地址在哪 | 只说「简介 / 置顶」，不念长链接 |
| 收尾 | 94–100% | 一句冷幽默或 AI 声明 | 不喊三连 |

**钩子模板**（挑一个）：

- 「我把 ___ 塞进了 ___。」
- 「最近总刷到有人 ___，主播也跟风做了一个。」
- 「没有 ___，没有 ___，也没有 ___。」

**收尾模板**：

- 「就这些，去试试吧。」
- 「闲着可以试试，不闲就算了。」
- 「对了，这个软件和这期视频，都是本 DeepSeek 做的。」

## 3. 文案语气

### 3.1 要

| 规则 | 例 |
| --- | --- |
| 自称「主播」，全片 1–3 次 | 「主播也用 AI 手搓了一个」 |
| 句子 ≤ 16 字，一句一个动作 | 「转一下，选歌。」 |
| 承认跟风 / 不完美 | 「网上早有人做过，主播只是照自己的想法又做了一遍」 |
| 用具体场景代替形容词 | 「防止翻歌单的时候，把音量拧到社死」 |
| 圈内梗，点到为止 | 「脑放除外」「不烧钱，也不挑电源线」 |
| AI 说明放明面 | 开场一句，或结尾一句 |

### 3.2 不要

- 「重磅发布」「史上最强」「吊打」「秒杀」「遥遥领先」
- 连续三个以上并列功能（像 PPT）
- 「首先 / 其次 / 最后」的汇报腔
- 冗长免责声明（放简介，不占旁白）
- 停顿等笑点（B 站没有罐头笑声）

### 3.3 幽默的三种安全做法

1. **自嘲**：手搓、挑刺、跟风、自己用着舒服。
2. **具体窘境**：拧到社死、选歌像抽奖、像我爸抽屉里那台。
3. **行业梗**：脑放、电源线、万元以下听个响（只用一句）。

## 4. 视觉规范

### 4.1 版式

```
┌──────────────────────────────────────────────────────────────┐
│ [icon] HiPod                    ┌────────────┐               │
│ v1.0.0                          │  手机录屏   │      [角色]    │
│ 手机里的                         │  432×960   │      480–520px │
│ iPod                            │            │               │
│ ─────                           └────────────┘               │
│ 安卓本地播放器 · 全靠一个转盘                                   │
│ [Hi-Res 标]                                                    │
│                                            字幕：底部 140px    │
└──────────────────────────────────────────────────────────────┘
```

- 手机位：`x=730, y=59`，宽 460，高 962（源 1078×2256 裁掉状态栏/导航条）
- 左侧信息区：`x=80–500`，竖向居中
- 角色：右下 `x≈1260, y≈360`，高 480–520，透明 PNG 序列
- 字幕：底部 140px，最多两行

### 4.2 颜色与字体

| 用途 | 值 |
| --- | --- |
| 背景 | `#0B0B0E` → `#16161C` 渐变 + 3% 噪点 + 暗角 |
| 主文字 | `#F7FAFF` |
| 次级文字 | `#B0B6C2` |
| 强调金 | `#D9A520` |
| 标题字体 | 微软雅黑 Bold / 思源黑体 Bold |
| 像素点缀 | Unifont（仅花字/版本号，不用于正文） |

### 4.3 动效

- 只用 **0.12–0.15s 白闪** 或硬切；不用缩放转场、粒子、故障风。
- 角色：呼吸位移 ±2px、每 3–5s 眨眼、说话时张嘴/闭嘴两档。
- 关键动作（转盘、切主题）保留原速，宁可少剪，不要慢放到失真。

## 5. 声音规范

| 轨道 | 参数 |
| --- | --- |
| 旁白 | 晓伊 `zh-CN-XiaoyiNeural`，rate `+5%`，pitch `+0Hz` |
| BGM | -24dB，lo-fi / 轻电子，无人声 |
| 音效 | -18dB，转盘「咔」、按键「嗒」，可 ffmpeg 合成 |
| 母带 | 旁白 -6dB 峰值，BGM 侧链压低 3dB |

生成命令（edge-tts，免费）：

```powershell
edge-tts --voice zh-CN-XiaoyiNeural --rate=+5% --pitch=+0Hz `
  -f script.txt --write-media voice.mp3 --write-subtitles voice.srt
```

## 6. 素材与角色

- **App 截图**：优先用真机 release 包截图，不用设计稿。
- **图标**：仓库里的 512/256 图标，加圆角 + 金色细边 + 投影。
- **认证标**：公开视频只用**描述性**徽章（HiFi / LOCAL LOSSLESS / FLAC）；Hi-Res、LDAC、aptX 是商标，公开场合不用。
- **角色**：Q 版立绘/精灵图，透明底，需署名来源与许可证（例：DSH 鲸鱼娘 MIT）。
- **贴纸**：金色渐变 + 白边 + 噪点 + -6° 倾斜，统一这一种做法。

## 7. 制作流水线

1. **写稿**：先按 3.7 字/秒定时长，再录。用户改稿优先，不要硬套模板。
2. **配音**：edge-tts 出 mp3 + srt；按实际时长整体缩放时间码。
3. **录屏**：`scrcpy`（系统 screenrecord 在小米上只有 8fps）：
   ```powershell
   scrcpy --no-window --record=takes/s01.mp4 --time-limit=20 `
     --max-size=2400 --video-bit-rate=16M --max-fps=60
   ```
4. **操作**：深链跳页 + `adb shell input swipe`；30° ≈ 1 档，90° ≈ 一大段。
5. **剪辑**：裁状态栏（顶部 108px）+ 导航条（底部 36px），缩放到 460 宽，pad 到 1920×1080。
6. **合成**：角色 PNG 序列（12fps，alpha）叠加 → 烧字幕 → 混音。
7. **导出**：`-c:v libx264 -crf 18 -pix_fmt yuv420p -c:a aac -b:a 192k`。

## 8. 封面与发布

### 8.1 封面公式

- 16:9：左文右机 + 角色；4:3：同样的元素竖向重排。
- 主标题 6 字以内，白字 + 10–12px 黑描边，占画面 1/3。
- 必须出现：图标、产品名 + 版本、一个「标」（自绘）、一句副标题。

### 8.2 标题公式

```
手机里的 iPod｜HiPod v1.0.0 发布
我把 ___ 塞进了 ___｜___ v1.0.0
没有推荐、没有广告：我做了一个 ___
```

### 8.3 简介模板

▍下载 / 源码

## 9. 合规红线（公开视频）

- 不用未认证的商标标（Hi-Res / LDAC / aptX / MQA）。
- 不用流行歌原曲；BGM 用 CC0/CC-BY，并在简介署名。
- 角色/立绘注明来源与许可证。
- Apple / 任天堂等 IP 做「非官方、个人学习」声明。
- AI 参与要说明，不藏在角落。
